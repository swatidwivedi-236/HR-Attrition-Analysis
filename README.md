# HR Employee Attrition Analysis

## Project Overview
Analyzed IBM HR dataset of 1,470 employees using SQL 
to identify key reasons for employee attrition.

## Tools Used
- MySQL Workbench
- IBM HR Analytics Dataset (Kaggle)

## Key Findings
1. Overall attrition rate is **16.12%**
2. Sales department has highest attrition **(20.63%)**
3. Overtime employees have **30%+** attrition rate
4. Low salary employees quit the most
5. New employees (0-2 years) have **29.82%** attrition
6. Sales Representatives most at risk **(39%)**
7. Bad work-life balance = **31.25%** attrition
8. Bad job satisfaction = **22.84%** attrition

## Conclusion
Young + New joiners + Sales role + Low Salary + Overtime
= Highest Attrition Risk
